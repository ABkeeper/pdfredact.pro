USER GUIDE • VERSION 3.0

PDF Redact & Extract Pro

Offline PDF redaction, OCR and structured data extraction to Excel — with visual review before applying changes.

Manual DrawSearchPIIRegExOCRTable → ExcelBatch

This guide covers both redaction and extraction workflows. PDF Redact & Extract Pro works locally on your PC; use Live Preview and Excel Preview to verify rules before creating final output.

Need to hide sensitive data?Use Draw, Search, Auto Detection, RegEx or Objects, then review Live Preview and Apply Redaction.
Need structured Excel data?Use Search and Table cards, Split/Merge output fields, review Excel Preview, then Apply Extract.
Working with scans?Create searchable OCR copies first, then use the normal Search, Auto and Table workflows.
Verification matters. Redaction and extraction rules can behave differently across layouts. Review the PDF preview and generated output before sharing or archiving results.
01

Quick Start

A reliable first workflow for a new document.

  1. Open a single PDF or add a source folder and build the file list.
  2. Choose the right rule type: manual Draw, Search, automatic detection, RegEx, Objects, or Table extraction.
  3. Turn on Live Preview. For extraction, also switch Preview to Extracted Table when needed.
  4. Adjust rules until the overlays and Excel Preview show the intended content.
  5. Use APPLY REDACTION or APPLY EXTRACT to create output files.

Fixed visual area

Use Draw. Choose Page-specific Draw if the rectangles differ by page.

Stable labels / values

Use Search and directional capture. Auto-fit can trim the result to found text.

Structured repeated rows

Use Table, define physical columns, then shape output with Split and Merge.

02

Files, Batch Queue and Page Mode

Choose what to process and where results are saved.

Batch queue

Find PDFs scans the source folder. Open Single PDF loads one document directly. Removing an item from the list does not delete the source file.

One-by-one mode

Use Process files one at a time when each PDF needs inspection or different rules. The current file can be redacted or extracted before moving to the next item.

03

PDF Preview, Navigation and Manual Tools

The preview is the central verification surface.

  • Area selects and moves existing manual areas.
  • Draw creates manual redaction rectangles.
  • Copy Text selects text from the PDF text layer.
  • Live Preview toggles detection overlays.
  • Locate Row links a table record in the PDF with the corresponding Excel Preview row.
  • Use Single Page or Continuous view. Zoom and Fit affect only the viewer, not the stored page-local Draw coordinates.

04

Search Tab

Find known text, labels and nearby values.

Text / RegEx Search

Use exact text, phrases or RegEx patterns. Enable multiline phrase matching when a known phrase is split across PDF lines.

Text-Based Area Redaction

Find a tag and capture an area Right, Left, Above or Below it. Area width/height define the search envelope when Auto-fit is off.

Additional Text-Based Area

A second independent text-area source that can be used for redaction or added to Table extraction output.

Simple / Advanced Context

Simple Context uses Distance around a keyword. Advanced Context supports multiple labels with independent capture profiles.

Auto-fit and Fit mode

Auto-fit value trims a captured area to detected text. The configured width still matters as the search envelope. Smart prefers a compact nearby value; Width searches across the configured width and then trims to the found text. Use Width when the value can extend far across the row.

Template behavior. Search settings such as Auto-fit, Distance, case sensitivity and source hiding are stored with the template so the same capture behavior is restored after restarting the program.
From Search to Extract. Search modules can be expanded or collapsed individually to keep the workspace compact. When a Search result should also become part of the extraction output, click Add to Extract. The corresponding Extract cards are then created in the Table workspace, and their output is reflected in Excel Preview.
05

RegEx Builder / Text Mask Generator v3.0

Build and test structured detection and selective-redaction patterns visually.

  • Flexible structure generalizes variable digits or text while keeping the visible structure.
  • Exact value escapes the supplied value for an exact-match pattern.
  • Mask can redact the entire value or preserve selected leading/trailing characters.
  • Copy Detection and Copy Redaction copy the generated patterns.
  • Send Detection to Auto / Send Redaction to Auto move the generated rule into the automatic RegEx module.

Multiple source examples

When you paste multiple non-empty examples on separate lines, each line is treated as an alternative value. The generated Detection pattern joins them with RegEx OR (|) instead of forcing the examples to appear sequentially.

Best practice: generate the rule, verify the green test panel, then test it in Live Preview on a representative PDF before batch processing.
06

Auto Detection

Combine common detectors with manual and Search rules.

PII

Detect email addresses, web/phone-like values, SSNs, cards, dates and faces. Date formats can be constrained to reduce false positives.

Currency

Detect configured symbols and extended currency formats. Review short currency codes on dense documents.

Address Blocks

Use profile, detection mode, labels, postal codes, street words, expansion and same-column constraints.

Custom RegEx

Use document-specific patterns that are not covered by the built-in PII detectors.

Keep Visible / Allowlist

Protect approved values from automatic redaction; optional normalization helps with phone/number formatting differences.

Faces / Images

Face detection supports scan DPI, shape and masking effects. Image handling can hide or filter images separately.

Automatic detection is a helper, not a substitute for review. Photos, unusual fonts, dense layouts and OCR errors can produce misses or false positives.
07

Objects and Visible Object Inspector

Inspect images and PDF objects that are not handled like normal text.

  • Image handling can hide images or filter by size. Use full-page image handling only when intentionally working with image-based pages.
  • Annotations / stamps are independent PDF objects and can often be removed without covering the page content beneath them.
  • Visible Object Inspector provides Scan, Pick, Add, Delete and Clear actions for supported objects.
  • Headers / footers can be excluded from extraction or hidden during redaction when the document repeats the same page furniture.
08

Page-specific Draw and Page-specific Rules Advanced

Use different manual areas or different rule profiles on individual pages of the same PDF.

Page-specific Draw

Only manually drawn rectangles become page-specific. Each Draw area belongs to the page where it was created and is not repeated on other pages.

Other active Search, Auto, PII, RegEx and detection settings continue to apply normally across the document. If those settings also need to differ from page to page, use Page-specific Rules.

Page-specific Rules

The rule settings themselves can vary by page. Use this mode when different pages require different Search, Auto, PII, RegEx, Table, extraction or other supported rule settings.

When you move to another page, the program saves the profile of the page you leave and restores the stored profile for the newly active page.

Which mode should I use?
Different manual rectangles only→ Page-specific Draw
Different Search / Auto / detection / extraction rules→ Page-specific Rules
Need both→ Enable both modes
Recommended view: Single Page. For page-specific work, Single Page is usually easier because it is always clear which page you are editing.Continuous View is also fully supported and can be useful when comparing adjacent pages or reviewing several page profiles while scrolling.
Continuous View detail. Page-specific Draw areas remain anchored to their original PDF page, so zooming and scrolling do not change their intended position.
09

Table Workspace

Extract physical table columns and combine them with values captured elsewhere on the page.

Table Options

Choose row detection, key position, flow/layout behavior, start/end markers, header handling, continuation behavior and optional boundaries. Use these controls to tell the extractor where records begin and how table segments continue across pages.

Manual Table Geometry

Manual Table Geometry is one editing mode for the complete physical table shape. It owns the outer table area, the vertical column separators and the header divider shown in PDF Preview. Automatic detection can provide the initial geometry; enable Manual Table Geometry when you need to correct it directly.

ControlWhat it does
Manual Table GeometryEnables direct editing of the physical table geometry. The orange horizontal geometry is reused on applicable pages; vertical table bounds are determined per page.
DrawDrag a rectangle around the table body in PDF Preview. This rectangle belongs to Table extraction/redaction geometry; it is not a normal redaction rectangle.
+ SeparatorClick inside the orange table area to add vertical column separators. Repeat for every required column. Existing separators and outer boundaries can then be dragged.
ClearRemoves only the internal vertical separators. The outer table area and Header are kept. Physical cards collapse to the remaining first column and can be restored with Undo.
ResetResets the outer table area, Header band and all manual separators. Column-card configuration is retained; confirmation and Undo are available.
RescanReads column captions and geometry again from the current manual area. Existing card settings are preserved when the column names still match.
Editing sequence. For a difficult table, enable Manual Table Geometry → Draw the table area → add or drag separators → set Header / First row → Rescan if you want the program to read captions from the corrected geometry → Refresh Preview.

Header and First row

Has header

The configured First row height is treated as the column-heading band. It is used for column names and is not exported as a data record. You can also drag the lower edge of the header band directly in PDF Preview.

No header

The first row remains data. The physical columns use generic names such as Column 1, Column 2, and so on until you rename them.

First row is measured in points and defines the first-row/header band inside the manually drawn area. Continue without headers allows following pages without repeated headings to be accepted only after the program checks the Key column, column positions, configured data types and several matching rows.

Page scope, Fixed and Auto Shift

Manual Table Geometry has one predictable document-wide geometry scope; there are no separate Reuse-up / Reuse-down controls in v3.0. The Page Mode on the Files tab still decides which pages are actually processed: Current page, All pages, Range or a custom page list.

Fixed

Reuses the same horizontal table position and column geometry on every applicable page.

Auto Shift

Keeps the same table shape and individual column widths, but may relocate the complete geometry when a matching header or strong typed-column structure is detected at a shifted position.

Preview before export. After changing geometry, Header / First row, Fixed / Auto Shift or Page Mode, use Refresh Preview and verify representative pages before Apply Extract. Undo / Redo covers Table / Extract configuration changes, but cannot reverse an Excel file already written to disk.

Search sources can be added to Extract and then displayed as cards below Physical Table Columns. This makes it possible to combine each table row with account numbers, periods, totals, customer data or other values located elsewhere in the document.

11

Split and Merge Output Fields

Transform captured values without changing the source PDF.

Split

Split one captured value into multiple output cards. Use literal separators, occurrences or visual-gap splitting depending on the source structure. Each child card can then have its own Type, Format, Key and alignment settings.

Short Split demo: configure the split, create child fields, and see the new Excel Preview columns.

Merge

Select compatible output cards and use Merge to combine related values into one output field. The merged card can be used like a normal output card, including as a Key. Excel Preview and final Excel output use the same merged value and order.

12

Excel Preview and Locate Row

Review the exact structured output before creating the workbook.

  • Use Pages per preview, From/To and Refresh Preview to limit expensive preview work on long PDFs.
  • Column order follows the configured output order, including Split and Merge fields.
  • Column alignment reflects the alignment selected in the corresponding output card.
  • Source PDF name/page columns can be included when required by the export workflow.
Use Preview as a validation step. If a split, merge, data type or record boundary is wrong, fix the card configuration before Apply Extract rather than repairing the workbook afterward.
13

OCR for Scanned PDFs

Create searchable copies while preserving the page image whenever possible.

  1. Use Auto — scanned pages only for mixed documents unless you intentionally need a different mode.
  2. Choose the document language and Balanced quality for a normal first attempt.
  3. Create searchable copies for the current, selected or all files. OCR copies are saved in an OCR subfolder inside the output folder.
  4. If desired, Replace Files list with searchable copies replaces the entries in the application list — not the original files on disk.
  5. Run Search, Auto Detection or Table extraction on the searchable copies.

Optional scan filters

Deskew, contrast improvement and binarization can help poor scans, but may alter the visible appearance of generated OCR copies. Leave them off for normal scans and enable them only when recognition needs help.

14

Templates and Presets

Reuse complete processing setups for recurring document types.

  • Templates can include Search, Auto, OCR, Table extraction, Split/Merge output cards, page scope and other workflow settings.
  • Stateful controls such as Auto-fit, Distance, case sensitivity, column alignment and Table output settings are restored with the template.
  • Page-specific Draw areas and Page-specific Rules profiles are stored when those modes are used.
  • Preset Templates in Options are editable starting points; use Save Template for your own exact reusable configuration.
After major layout changes in a source document, re-check the template on one file before processing a batch.

Troubleshooting

Common workflow checks before assuming a rule is broken.

Search or Auto Detection finds nothing
The PDF may be image-only. Use Copy Text or Find to confirm there is a usable text layer. If not, create an OCR searchable copy and run the rule again.
Auto-fit captures too little text
Check the configured Area width and Fit mode. Smart prefers a compact nearby value; Width searches across the configured width before trimming to the found text. For Simple Contextual Search, also verify Distance.
Excel Preview does not match the intended output
Check Key selection, row mode, data Type, Split/Merge configuration, output order and column alignment. Use Locate Row to trace the incorrect cell back to its PDF source.
A multi-line table value is attached to the wrong record
Review Multiline, Gap ↑ / Gap ↓, Anchor and row boundaries. If the physical table itself is offset, adjust Manual Table Geometry or Auto Shift before changing output transforms.
Manual Table Geometry works on one page but is offset on another
Check Page Mode first. With Layout = Fixed, the same horizontal geometry is reused on every applicable page. If the whole table moves between pages, use Auto Shift; it relocates the geometry as one rigid shape while preserving individual column widths. Then Refresh Preview and verify the affected pages.
Page-specific settings appear on the wrong page
Confirm whether Page-specific Draw or Page-specific Rules is enabled. In Continuous View, scroll to the intended page before editing. Use Page-specific Draw for manual rectangles only; use Page-specific Rules when the rule controls themselves must differ.
OCR result looks visually different
Optional preprocessing filters can change the generated OCR copy. Disable Deskew/Contrast/Binarize unless the scan actually needs them, and keep the original document unchanged.
Face, address or PII detection has false positives
Adjust detector settings, reduce aggressive/extended modes where appropriate, use the allowlist, or replace automatic detection with a more specific Search/RegEx rule for that document type.
The output must be verified
Always open the generated PDF or Excel file and check the result independently. For redaction, verify that hidden content cannot be selected, copied or recovered from the output.

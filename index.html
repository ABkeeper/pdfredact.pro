FAQ

Before you download.

Does the app upload PDFs to a cloud service?

No. The application is designed to process documents locally on your Windows PC.

Can it work with scanned PDFs?

Yes. Use the OCR workflow to create searchable copies, then apply Search, Auto and Table tools.

Can I convert PDF data and tables to Excel?

Yes. Use Search-to-Extract or Table tools to extract PDF data, structure it with Split/Merge, review it in Excel Preview, and create the final Excel output with Apply Extract.

Is this a subscription?

No. The full version is sold as a one-time purchase.

Is the Windows app digitally code-signed?

Not yet. The current release is an unsigned Windows application, so Windows Smart App Control or restrictive corporate security policies may prevent it from running. Code signing is planned for a future release. If your organization only permits digitally signed applications, please wait for a future signed release.
